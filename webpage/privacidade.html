Política de privacidade

IdleHub · vigente desde 20 de novembro de 2026 · responsável: Iury França

O IdleHub não coleta, não envia e não guarda dados pessoais em nenhum servidor. Não existe servidor do IdleHub, nem conta, cadastro, telemetria, análise de uso, anúncios ou atualização automática.

O que fica no seu computador

  • A lista de jogos (nome, link e ícone), os apelidos das contas, os espaços mistos e as preferências (tema, idioma, layout).
  • A sessão de cada conta (cookies e dados que o próprio jogo grava), separada por conta.

Esses dados ficam só na pasta do app no seu usuário do Windows. "Remover conta" apaga a sessão daquela conta. Desinstalar a versão da Microsoft Store apaga tudo; na versão instalada pelo GitHub, apague também a pasta %APPDATA%\idlehub.

Conexões com a internet

  • O app abre apenas os sites de jogos que você adiciona. O que você envia a um jogo (o login, por exemplo) vai para o servidor desse jogo, como num navegador, e segue a política de privacidade dele. O IdleHub não vê, não copia e não repassa esses dados.
  • A única requisição feita pelo próprio app é o ícone (favicon) de cada jogo, pedido ao site do próprio jogo, só por HTTPS. O ícone é guardado no seu computador.
  • Links externos só abrem no seu navegador quando você clica.

Monitor de recursos

A tela Monitor lê o uso de processador, memória, placa de vídeo, disco e rede do Windows enquanto está aberta. Nada disso é gravado nem enviado.

Crianças

O IdleHub não coleta dados de ninguém, inclusive de crianças.

Contato e código-fonte

O código é aberto (licença MIT) e pode ser conferido em github.com/iuryfranca/idlehub. Dúvidas sobre privacidade: abra uma issue em github.com/iuryfranca/idlehub/issues.

Privacy policy

IdleHub · effective November 20, 2026 · controller: Iury França

IdleHub does not collect, send or store personal data on any server. There is no IdleHub server, account, sign-up, telemetry, usage analytics, ads or automatic update.

What stays on your computer

  • Your list of games (name, link and icon), account nicknames, mixed spaces and preferences (theme, language, layout).
  • Each account's session (cookies and data the game itself stores), kept separate per account.

This data stays only in the app's folder in your Windows user profile. "Remove account" deletes that account's session. Uninstalling the Microsoft Store version deletes everything; for the version installed from GitHub, also delete the %APPDATA%\idlehub folder.

Internet connections

  • The app only opens the game websites you add. Whatever you send to a game (your login, for example) goes to that game's server, as in a browser, under that game's privacy policy. IdleHub does not see, copy or share that data.
  • The only request the app makes on its own is each game's icon (favicon), fetched from that game's own website over HTTPS. The icon is stored on your computer.
  • External links only open in your browser when you click them.

Resource monitor

The Monitor screen reads processor, memory, graphics, disk and network usage from Windows while it is open. None of it is saved or sent.

Children

IdleHub collects no data from anyone, including children.

Contact and source code

The code is open source (MIT license) at github.com/iuryfranca/idlehub. Privacy questions: open an issue at github.com/iuryfranca/idlehub/issues.
